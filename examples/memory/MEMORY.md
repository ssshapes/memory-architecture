# Memory index

*One line per memory: title, link, and a hook short enough to scan. This file is
loaded into every session, which makes it a cache with a read ceiling rather than
a document. The validator blocks writes that push it past the ceiling, because
past roughly 24KB it gets silently truncated and the bottom of the index stops
existing. Detail belongs in the memory files, never here.*

*Every memory below is fictional — invented people, dates and projects that exist to show the format. Nothing in examples/ describes a real person or household.*
